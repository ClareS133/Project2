## Deployment Steps
1. Create a new public repository on GitHub  
2. Upload all project files  
3. Go to **Settings / Pages**  
4. Under **Source**, select `main` branch and `/root` folder  
5. Click **Save**  
6. The site will be live at:  
   `https://<ClareS133>.github.io/project2/`
